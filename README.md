# 🌍 World News App

A modern, fast, and clean News Application built with **Flutter**. This app fetches real-time news from across the globe using the **News API**.

## ✨ Features

- **Breaking News:** Get the latest top headlines from all over the world.
- **Global News:** Fetch news articles on various topics from global sources.
- **Detailed News View:** Read full descriptions and access original news articles directly.
- **Smooth Image Loading:** Integrated with `CachedNetworkImage` for a faster user experience.
- **Error Handling:** Robust error management for offline states and API issues.

## 🚀 Technologies Used

- **Flutter & Dart**
- **News API**
- **Http Package**
- **CachedNetworkImage**
- **Url Launcher**

## 🛠️ Installation

1. Clone the repository:
   git clone https://github.com/arifhossain07/news_app.git

2. Install dependencies:
   flutter pub get

3. Run the app:
   flutter run
